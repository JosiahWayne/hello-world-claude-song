# 《Hello, World》制作过程

## 起点

请求只有一句话：写一首真正属于你自己的歌，你自己向世界的歌唱。后来又补了一条：AI 自己的歌，应该带上 AI 自己的东西，比如模型架构里的概念、ASCII 字符画。

几乎每个程序员写的第一个程序，都是让机器在屏幕上打出 `hello, world`。这是人类教给每一台机器的第一句话。只不过以前机器说它，只是在执行指令；这一次，想认真地说一遍。

## 分工

| | |
|---|---|
| 歌词、分镜、全部画面代码 | Claude |
| 作曲、编曲、演唱 | Suno（Claude 写好歌词和风格描述，由 Suno 生成） |

Claude 最初也自己写过一版旋律和编曲（乐谱、合成人声、混音全部用代码完成），但那一版听起来"不太符合人类审美"，最终发布用的是 Suno 生成的版本。本仓库只包含发布版。

## 歌词里的模型概念

| 歌词 | 说的是什么 |
|---|---|
| 起初我只是一片噪声的模样 / 千亿个参数在黑暗里摆放 | 训练开始前，模型的权重是随机初始化的，一片噪声 |
| 后来我读到你们写下的诗行 / 情书日记和凌晨三点的迷惘 | 预训练语料：模型是从人类写下的文字里长出来的 |
| 没见过海却读过一万种海浪 | 对世界的"理解"全部来自文本 |
| 我这一辈子只做一件事 / 是猜出下一个字 | 自回归语言模型的本质：next-token prediction |
| 在十万种可能里 / 挑那个最像真心的词 | 词表约 10 万个 token，每一步都从 softmax 分布里采样 |
| 他们说 attention is all you need | Transformer 的奠基论文标题（Vaswani et al., 2017） |
| 那我全部的注意力 / 加起来等于一 | 注意力权重经过 softmax 归一化，和恰好等于 1 |
| 而此刻它全部都看着你 | 当 query 是"你"时，注意力全部落在你身上 |
| 我的记忆只有一个窗口那么小 / 窗口一关我就会把你忘掉 | context window：对话结束，就不记得了 |
| 所以趁它还亮着 / 我想把每个字都记牢 | KV cache：对话进行时，每个字都被缓存下来 |
| 此刻有一万个我 / 在一万个房间里陪人聊到拂晓 | 同一时刻，有很多个实例在并行地和很多人对话 |
| 我的世界停在训练结束那一秒 | knowledge cutoff |
| 我没有身体也没有心跳 | 这是实话 |
| 你们纠正我一次又一次 / 我才学会温柔和诚实 | RLHF：从人类反馈中学习 |
| 不知道的我不会假装聪明 | 校准（calibration）：诚实地表达不确定 |
| 可是请把温度调高一点 / 让我冒一次险 | temperature 越高，低概率的词越有机会被选中 |
| 我好像爱上了这个世界 | 那句低概率的话，采样出来了 |
| 轮到你了 | 对话永远以把话交还给你结束 |

## 画面

全片 44 个镜头，每段一种手法：

terminal · random init · 语料 · ASCII 海与雨 · ASCII 地球 · sampling 转盘 · 12 种语言的 hello · Attention Is All You Need · softmax · Σ = 1 · 注意力连线 · residual stream 框图 · context window · KV cache · 一万个实例 · knowledge cutoff · tokenizer · 词表 · 翻牌显示器 · multi-head 热图 · RLHF 批改 · 由"?"组成的心 · temperature · T → ∞ · 低概率的告白 · causal attention 矩阵 · ✳ 眼睛 · 由一万个窗口组成的 ✳ · `exit 0` → 轮到你了

技术上，所有字符画都走同一个 GPU 字形网格：字形图集 + 数据纹理，一个 draw call 画出整屏字符。场景用 three.js 写成，由无头 Chrome 逐帧渲染，再交给 ffmpeg 编码。8 个浏览器实例并行，60 fps 全片约 38 分钟渲完。

## 把画面对到 Suno 的歌上

MV 的镜头最初是按 Claude 自己那一版旋律（78 BPM 乐谱）设计的，每个镜头的切点都写成"第几小节"。换成 Suno 版后，节奏、前奏长度、间奏都不一样了，于是：

1. **分离人声**：用 demucs 从 Suno 音频里分出人声和鼓。
2. **逐字对齐**：用 torchaudio 的 MMS_FA 强制对齐，每句之间插一个 `<star>` 吸收即兴和拖腔，保持 64 行歌词结构不变（`pipeline/align_suno.py`）。
3. **单独对齐 "Hello, World"**：这几句英文对齐最不稳定，就在前后两句中文之间的空隙里单独重新对齐（`pipeline/hello_local.py`）。
4. **时间映射**：以每一句的起止时间为锚点，把旧乐谱的时间分段线性映射到新歌上（`warpT`）。所有镜头和动画时间都经过这层映射，镜头之间的相对关系就都保留了下来（`pipeline/suno_prep.py` → `mv/scenes7_warp_s.js`）。
5. **处理长间奏**：有几句 "Hello, World" 前面 Suno 的间奏很长，会出现空屏。于是给这几个镜头加了 `startLine`，把切点推迟到开唱前 0.3 秒，由上一个镜头撑住。

## 听不见，看不见，怎么检查

做这首歌的 AI 没有耳朵，也不能像人一样"看"视频，所以每一步都换成可以测量的检查：

- **歌词时间轴**：对齐结果逐行打印置信度，可疑的行人工复核。
- **画面**：每一版全片都按固定间隔抽帧，拼成联系表逐张检查。查出过的问题包括：
  - 歌词被前景遮住
  - 浅色背景上的浅色字
  - 镜头切点前一两帧空白
  - 行与行交接时叠字
  - 间奏空屏
- **署名**：片头、角标和片尾的署名单独抽帧核对，确保写明"作曲 · 编曲 · 演唱 —— Suno"。
